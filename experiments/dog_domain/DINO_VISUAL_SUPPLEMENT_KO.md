# DINO 사진 단독 보완 평가

2026-09-18. 기존 5인 평가의 결과를 확인한 후 추가한 탐색적 비교다.

- 기존 연구 파일과 평점은 변경하지 않는다.
- 같은 30개 참고 사진, 같은 611개 후보, 같은 DINOv3 모델·전처리·revision을 사용한다.
- 이미지 단독 점수는 정규화된 DINO 참고 사진과 후보 사진 특징의 내적이다. 동점은 기존 후보 순서로 해소한다.
- 상위 5개 150쌍 중 기존 평가 풀에 포함된 127쌍의 평점을 재사용한다.
- 남은 23쌍만 기존 평가자 R1–R5가 같은 번호로 평가한다. 신규 참여자로 대체하지 않는다.
- 질의 안에서 중복 제거하며, 서로 다른 참고 사진에 대한 같은 후보는 별도 쌍이다.
- 방법명, 순위, 속성 조건은 숨기고 기존 0–3점 지침을 유지한다.
- 평가 완료 후 452쌍의 공통 풀로 네 방법 모두를 재집계한다. 새 풀과 기존 풀의 nDCG를 혼합하지 않는다.
- 모든 추가 평점이 없으면 최종 네 방법 점수를 출력하지 않는다.
- 원래 zero-IDCG=0 규칙과 positive-IDCG 질의만의 민감도 분석을 함께 보고한다. 확장 풀에서 positive 질의 수가 달라질 수 있으므로 다시 계산한다.
- 확장된 후보 풀과 후속 평가 시점의 영향, 기존 결과를 확인한 연구 참여자의 사전 지식은 해석의 제약이다. 추가 실험으로 모든 편향이 제거되는 것은 아니다.

자료 위치: `D:/meongtamjeong_research/human_visual_dino_supplement_v1/`

준비: `python -m experiments.dog_domain.prepare_dino_visual_supplement`

완료 확인·병합: `python -m experiments.dog_domain.merge_dino_visual_supplement`

원래 평점은 최종 5인 집계에 사용한 SQLite 스냅샷에서 재사용한다. 웹 대시보드의 진행 중 점수는 원고에 자동 반영하지 않는다.
