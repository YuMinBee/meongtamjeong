# PetFinder 학습 후 핵심 재평가

2026-09-17. 영어 조건, 글 비중 0.20 고정. 비교 대상별로 후보 공고와 정답은 동일하다. 새 학습 모델은 3개 시드의 질의별 점수를 평균했다. 결과는 nDCG@10 × 100이다.

| 방법 | PetFinder | 한국 | 대만 |
|---|---:|---:|---:|
| CLIP 사진+글 | 48.45 | 35.21 | 37.81 |
| DINO 사진만 | 55.38 | 40.63 | 45.29 |
| DINO 사진+CLIP 글 단순 점수 결합 | 55.56 | 41.12 | 45.54 |
| PetFinder 학습 CLIP Linear 결합 | 54.95 | 37.79 | 41.61 |
| PetFinder 학습 DINO Linear 결합 | 58.18 | 42.74 | 47.08 |
| PetFinder 학습 DINO MLP 결합 | 58.24 | 42.77 | 47.04 |
| PetFinder 학습 DINO Flow 결합 | 58.25 | 42.96 | 47.45 |

주요 해석:

- PetFinder에서 학습한 결합은 한국·대만에 추가 학습하지 않고도 기존 CLIP 사진+글보다 높은 속성 검색 점수를 보였다.
- Flow의 DINO 사진 단독 대비 개선은 PetFinder +2.87, 한국 +2.32, 대만 +2.16점이다. 등록자/보호소 단위 paired bootstrap 95% 구간은 각각 [2.49, 3.25], [1.87, 2.80], [1.82, 2.54]이다.
- Flow의 CLIP 사진+글 대비 개선 구간은 각각 +9.80 [8.48, 10.94], +7.75 [5.69, 9.82], +9.64 [7.78, 11.45]이다.
- Linear·MLP도 비슷한 수준이다. Flow 구조 자체가 필수이거나 통계적으로 우월하다는 결론은 내리지 않는다.
- 기존 한국 학습 Flow의 영어 조건 점수는 한국 43.14, 대만 46.46이었다. 새 모델은 한국 42.96으로 소폭 낮고 대만 47.45로 높다. 학습량을 늘렸으므로 모든 평가에서 개선되었다고 주장할 수 없다. 기존 모델은 단일 실행, 새 모델은 3개 시드 평균이라는 차이도 있다.

범위 및 한계:

- PetFinder 1,618개, 한국 611개(채점 가능 610개), 대만 5,427개(채점 가능 5,422개)의 후보를 사용했다.
- 한국은 서로 다른 사진을 질의/후보로 사용하는 동일 공고 검색 R@1/5/10·MRR도 함께 저장했다. 대만과 이번 PetFinder 핵심 실험은 자기 공고를 제외하는 속성 검색이며 개체 식별 평가가 아니다.
- 한국/PetFinder는 색상 하나 이상 겹침과 크기 일치, 대만은 색상 집합과 크기 완전 일치로 기존 채점 규칙을 유지했다. 국가 간 절대 점수를 직접 비교하면 안 된다. 한국 프롬프트도 기존 영어 캐시를 유지했다.
- 구간은 시드 평균에 대한 군집 부트스트랩이다. 시드 변동 전체를 포함하지 않으며 다중 비교 보정 전 탐색적 구간이다. 한국·대만은 기존에 확인했던 자료로 완전한 신규 확증 평가가 아니다.
- 색상·크기 충족도는 주관적 취향, 얼굴 형태 보존, 성격 조건 이해의 직접 증거가 아니다.
- 한국·대만의 5개 학습 없는 기준선은 과거 질의별 점수와 허용 오차 0.000002 이내에서 재현됐다. 대만 영어 텍스트 캐시 해시도 검증했다.
- 조건 변경, 한국어 보조 평가, ResNet 비교, 새 공고 확증 평가는 별도 후속 실험이다. 기존 논문 파일 수치를 자동 교체하지 않았다.
