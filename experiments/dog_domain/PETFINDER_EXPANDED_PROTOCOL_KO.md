# PetFinder 공고 정보 확장 실험 v2

2026-09-17. 아래 설정은 확장 실험 결과를 보기 전에 고정한다. v1 체크포인트·분할·결과를 보존한다.

## 학습

동일한 학습 5,252 / 검증 844 / 테스트 1,618 공고와 동결된 이미지 특징을 재사용한다. 색상·크기 템플릿에 더해 품종, 월령, 성별, 털 길이, 예방접종·구충·중성화의 기재 상태, 기재 건강 상태, 지역, 입양비 정보를 영어 프로필로 구성하고 원래 설명문을 함께 사용한다. 알려지지 않은 항목을 추정해서 채우지 않는다. 이름, 공고·등록자 ID, 사진·영상 개수, 입양 소요 기간 정답은 학습 입력에서 제외한다. 설명문의 URL·이메일·전화번호 패턴은 제거한다.

CLIP 문맥 길이 때문에 설명을 앞부분에서 잘라 버리지 않고, BPE 토큰 60개씩 나누어 각 조각을 인코딩하고 정규화 평균한다. 구조화 프로필과 설명 벡터를 동일 비중으로 평균해 전체 프로필 벡터를 구성한다. 원래 설명문은 번역하지 않으므로 영어 이외의 표현도 포함될 수 있다. 전체 프로필을 이미지 공간에 정렬하는 것은 약한 이미지–문장 대응 학습이며, 비시각적 속성을 사진에서 판별할 수 있다는 가정이 아니다.

v1의 다중 양성 색상·크기 목적과 전체 프로필–같은 공고 이미지의 대칭 대조 손실을 1:1로 결합한다. 학습 시 텍스트 입력은 전체 프로필·구조화 프로필·설명 중 하나를 균등하게 선택한다. CLIP Linear, DINO Linear/MLP/Flow에 같은 자료·손실을 적용하며, 세 시드와 최대 epoch·조기 종료 설정은 v1과 동일하다. 검증 목적도 두 손실의 동일 비중 평균으로 고정한다. 조기 종료는 테스트 점수를 보지 않는다.

## 평가

1. 기존 색상·크기 핵심 평가를 같은 공고·영어 프롬프트·글 비중 0.20으로 반복한다. v1 대 v2를 비교하여 정보 확장의 이득과 손실을 모두 보고한다.
2. PetFinder 테스트에서 색상·크기에 나이 구간, 성별, 털 길이, 주 품종을 하나씩 더한 질의를 평가한다. 나이는 12개월 이하 / 12개월 초과 84개월 이하 / 84개월 초과이며 0개월은 미상으로 제외한다. 채점은 조건의 교집합이다. 같은 공고를 후보에서 제외한다. 각 조건의 채점 가능 질의 수를 보고한다.
3. 비시각적 조건을 위해 후보 프로필의 CLIP 텍스트 특징을 검색하는 경로를 별도로 비교한다. 이미지 점수 0.8 + 질의–후보 프로필 텍스트 점수 0.2를 사용하며 CLIP 이미지와 DINO 이미지에 같은 텍스트 경로를 제공한다. 이는 구조화 항목과 설명문을 사용하는 별도 입력 구성이다.

## 행동 조건 예비 실험

테스트 설명문의 명시적인 표현을 고정 규칙으로 추출하여 활동량·사람 친화성·다른 개와의 친화성을 각각 분석한다. 부정·상반 표현이 있거나 근거가 없으면 평가 대상에서 제외하고, 미기재를 부정으로 간주하지 않는다. 규칙으로 확인된 긍정/부정 공고만을 후보로 구성한다. 질의 표현은 가능한 한 추출 키워드와 다른 문장을 사용한다. 사진 기반, 정렬 결합, 후보 설명문 검색 및 설명문 점수 결합을 비교한다. 이 자동 약한 라벨 평가는 공고에 기록된 행동 정보의 검색 가능성에 대한 탐색이며 실제 성격이나 사람 판정에 대한 정확도 검증이 아니다. 규칙·라벨 분포·제외량과 독립적인 사람 검증의 필요성을 보고한다. 표본이 작거나 한쪽 라벨만 있으면 그 축은 점수를 만들지 않는다.

## 논문 시각 자료

실제 테스트 사진으로 모델별 상위 검색 결과를 나란히 제시한다. 선택 규칙과 공고 ID·순위를 기록하고, 개선 사례와 개선되지 않은 사례를 함께 표시한다. 사진에서 성격을 판정한 것으로 표시하지 않는다. 결과표 및 보조 실험, 추후 독립적인 행동 라벨 검증 방향을 원고·Word·PDF에 함께 반영한다.
