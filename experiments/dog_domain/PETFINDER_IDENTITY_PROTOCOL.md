# PetFinder 같은 개 다시 찾기 평가 프로토콜

2026-09-28 작성. **결과를 보기 전에 고정한 계획이다.** 변경 시 하단 기록에 추가한다.

## 목적

공고 기재 속성(silver label)에 의존하지 않고, 정답이 구성상 확정되는 객관적 지표로
유기견 공고 사진에서의 검색 성능을 보인다. 한국 611쌍 평가를 두 번째 출처(PetFinder,
말레이시아)로 확장한다.

## 과제

- 대상: PetFinder test 1,618마리(기존 논문과 동일한 선정·중복 제거) 중 사진이 2장 이상인 개체.
- 질의: 각 개체의 **두 번째 사진**(파일 번호 순).
- 갤러리: test 1,618마리 전체의 **대표 사진**(첫 번째 사진, 기존 평가에서 쓰던 것).
- 정답: 질의 개체 자신의 대표 사진. 갤러리의 나머지 1,617장은 방해 항목.
- 거의 같은 사진 제외(주 분석): 질의·정답 사진이 바이트 동일하거나, 대만 평가와 같은 규칙
  (9×8 dHash 해밍 거리 ≤ 3 AND 32×32 썸네일 평균 절대 차이 < 0.035)에 걸리면 제외한다.
  제외 전체 결과는 민감도 분석으로 함께 보고한다.

## 두 가지 입력 조건

1. **사진만**: 다른 사진 한 장으로 같은 개를 찾는다.
2. **사진 + 외형 설명**: 잃어버린 개를 찾는 상황을 가정해 질의 개체 자신의 색·크기 문장
   (`Find a {size} dog whose coat is {colors}.`, 기존 주 평가와 동일)을 사진과 함께 넣는다.
   결합은 각 모델 공간에서 사진 0.8 + 글 0.2, 가중치 탐색 없음.

## 방법

사진만: `CLIP_image`(ViT-B/32), `DINO_image`(DINOv3-B), `DINOL_image`(DINOv3-L),
`dinotxt_image`, `t2d_image`.
사진+글: `CLIP_mix`, `dino_linear_mix`(논문 v2 체크포인트), `dinoL_linear_mix`, `dinotxt_mix`, `t2d_mix`.
학습 헤드는 시드 17/29/43 질의별 평균. 모든 헤드는 PetFinder train/validation만으로 학습했고
test 사진은 학습·선택에 쓰지 않았다.

## 지표와 구간

R@1(주), R@5, R@10, MRR. 등록자(rescuer) 단위 paired cluster bootstrap 2,000회,
다중비교 보정 없음(탐색적).

## 사전 지정 비교

1. `DINO_image − CLIP_image` (시각 표현 교체 효과)
2. `dino_linear_mix − CLIP_mix` (논문 주 방법 vs 기존 서비스 방식)
3. `dino_linear_mix − DINO_image` (외형 설명 추가가 개체 찾기에 주는 영향; 해가 되는지도 확인)
4. `DINOL_image − dinotxt_image`, `dinoL_linear_mix − dinotxt_mix` (dino.txt와의 비교)

## 해석 규칙

- "같은 공고 = 같은 개"는 공고 구조에 따른 정답이며, 한 공고에 여러 마리가 찍힌 사진이나
  잘못 올라간 사진이 섞일 수 있다(Quantity=1 공고만 사용해 완화).
- 같은 날 같은 장소에서 찍은 사진이 많아 배경이 단서가 될 수 있다. 이는 개체 인식 능력의
  상한 추정이며, 서로 다른 날 찍은 실종·보호 사진 매칭 성능을 직접 뜻하지 않는다.
- 질의·갤러리 사진은 모두 같은 장비(RTX 3090)에서 새로 인코딩한다. 갤러리 대표 사진의
  CLIP·DINOv3-B 특징은 기존 RTX 4090 캐시와 비교해 최대 차이를 기록한다(장비 간 일관성 점검).
  인코더는 모두 고정이다.
