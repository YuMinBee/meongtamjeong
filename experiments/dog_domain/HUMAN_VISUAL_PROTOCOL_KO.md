# 외부 사진 30개에 대한 시각 유사도 평가

## 고정한 평가 설계

- 자료: Oxford-IIIT Pet의 사모예드·포메라니안·퍼그·비글·시바견·휘튼 테리어 각 5장, 총 30장.
- 선정: seed 20260918, GitHub 미러의 고정 커밋에서 파일명 목록을 정렬한 후 무작위 추출. 이미 관찰한 각 품종의 `_1.jpg`는 제외. 선정 파일은 검색 실행 전에 저장했다. 결과에 따른 사진 교체는 하지 않는다.
- 검색 후보: 기존 한국 공고 611건. 입력 사진과 후보의 동일 픽셀 중복은 없으며 근접 복제본까지 배제한 것은 아니다.
- 조건: 기존 여섯 품종 예시의 색상·크기 요청을 그대로 품종별 5장에 적용한다. 사진 자체의 정답 속성이나 실제 사용자 선호를 뜻하지 않는다. 독립적인 조건은 여섯 종류이며 전체 선호의 대표 표본이 아니다.
- 방법: CLIP 사진+텍스트, DINO Linear 사진+정렬 텍스트, DINO Linear 정렬 텍스트 단독. 학습된 모델은 17/29/43 시드의 **점수 평균으로 한 순위**를 생성한다.
- 이미지 비중: 기존 고정값 0.8. 새 검증 민감도에서 선택한 값이라고 주장하지 않는다.
- 각 방법 Top-5를 합치고 질의 안에서 중복을 제거하여 429쌍을 구성했다. 세 평가자가 같은 쌍을 모두 평가하므로 총 1,287개 점수가 필요하다. 같은 후보라도 참고 사진이 다르면 별도 쌍이다.

## 평가자 지침

방법·순위·조건·품종명·공고 메타데이터를 보여주지 않는다. 참고 사진과 후보 사진만 보고 독립적으로 평가한다. 평가자마다 질의 순서와 질의 내 후보 순서를 고정 무작위화한다. 모델의 예상 우열을 평가자에게 알려주지 않는다.

- 0: 전혀 닮지 않음
- 1: 일부 외형 특징만 유사함
- 2: 전반적으로 유사함
- 3: 매우 유사함

얼굴 형태, 몸의 형태와 비율, 털 길이·질감을 기준으로 비교한다. 사진 배경·화질·촬영 각도 자체나 품종명 맞추기로 채점하지 않는다. 요청한 색상 변경과의 충돌을 줄이기 위해 **색상의 일치 자체는 주된 시각 기준에서 제외**한다. 체형의 시각적 비율은 평가하지만 사진만 보고 실제 kg을 추정하지 않는다. 실제 체중 조건은 공고 기록으로 별도 판정한다. 이 평가를 사용자의 ‘진짜 취향’ 조사로 해석하지 않는다.

사진을 판별할 수 없으면 ‘판단 불가’를 선택한다. 미평가·판단 불가는 0점으로 채우지 않는다. 휴식 후 이어서 평가할 수 있으며 평가자 간 협의는 하지 않는다.

## 지표와 집계

후보별 visual relevance는 세 평가자의 0–3점 평균이다. 속성 관련성 a는 요청 색상이 후보의 색상 라벨에 포함되고 체중 구간이 같을 때 1, 그 외 0이다. joint relevance는 a × visual relevance이다. gain은 지수 변환 없이 relevance 자체를 사용한다.

visual nDCG@5와 joint nDCG@5의 IDCG는 **세 방법 Top-5의 공통 판단 풀**에서 이상적 상위 5개를 골라 계산한다. 후보 전체 611건을 사람이 판정한 nDCG로 부르지 않고 pooled nDCG로 명시한다. 새로운 방법을 추가하면 판단 풀을 다시 구성해야 한다. 모든 방법에 같은 쿼리와 같은 분모를 적용한다. IDCG가 0인 질의는 점수 0으로 포함하고 개수를 별도 보고한다.

모든 공통 후보에 세 점수가 모인 질의만 완결 질의다. 연구자 화면은 미완료 기간 동안 비교 점수를 공개하지 않는다. 30개 질의가 모두 완결되면 방법별 평균과 질의별 결과, 속성 P@5, ordinal Krippendorff's α를 출력한다. α의 기대 불일치가 0이면 계산 불가로 표시한다. 평가자가 아닌 질의를 분석 단위로 삼는다. 6품종·30질의의 소규모 탐색 연구이며 광범위한 사용자 일반화를 주장하지 않는다.

평가가 끝나면 대표 성공·차이·실패 사례 2–3개를 동일 선택 규칙으로 정하고 그 선택 규칙을 원고에 기록한다. 현재 원고에는 사람 평가 완료·시각적 우위가 입증되었다는 문장을 넣지 않는다.

## 실행 및 보관

서버 실행: `python -m experiments.dog_domain.visual_study_server`

로컬 관리 화면: `D:/meongtamjeong_research/human_visual_study_v1/OPEN_DASHBOARD.url`

동일 LAN 접속이 필요하면 `--host 0.0.0.0`을 추가하고 해당 컴퓨터의 LAN 주소로 접속한다. 이는 인터넷 공개 배포가 아니다. 관리자는 전용 링크를 각각 배부한다. 링크를 가진 사람은 해당 평가자로 접근할 수 있으므로 관리 링크는 평가자에게 제공하지 않는다.

데이터와 SQLite, 원본 선정 목록, 체크포인트 해시는 `D:/meongtamjeong_research/human_visual_study_v1/`에 저장한다. SQLite는 자동 저장과 수정 이력을 유지하며, 각 평가자와 연구자는 JSON을 내보내 별도 백업할 수 있다. 실제 평가 데이터는 Git에 포함하지 않는다.
