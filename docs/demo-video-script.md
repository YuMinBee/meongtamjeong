# 멍탐정 공모전 데모 영상 대본·스토리보드

최종 export 목표 러닝타임은 **2분 55초**이며, 인코더 반올림을 포함해도 공식 상한 3분을 넘지 않게 완성본을 `2:55~2:58` 안에 둡니다. 아래 종료 카드도 이 시간에 포함합니다. 핵심 메시지는 “AI가 입양 적합성을 판단한다”가 아니라 **원하는 외형의 실제 활성 공고를 찾고, 확인 가능한 조건으로 먼저 볼 후보를 좁힌 뒤, 추측이 필요한 내용은 문의 질문으로 넘긴다**입니다.

## 촬영 전 고정 준비

- `docs/demo-runbook.md`의 readiness 검사에 통과한 최신 active-only 스냅샷과 인덱스를 사용합니다. 기준일이 지난 공고로는 “현재 보호 중”을 시연하지 않습니다.
- `APP_ENV=contest`에서 서버를 실행하고, 24자 이상의 별도 서비스 키를 준비합니다. 키 입력과 연결 검증은 녹화 전에 끝내고 `/demo`의 연결 상태만 보여줍니다.
- 최신 상태 재확인을 시연하려면 유효한 `ANIMAL_API_KEY`를 녹화 환경에만 설정하고, 사전 요청으로 성공 여부를 확인합니다. 키 값은 화면·로그·영상에 노출하지 않습니다.
- 참고사진뿐 아니라 결과 카드와 원문 화면에 녹화될 공고 사진도 촬영·재배포 범위를 서면으로 확인합니다. 확인 전에는 공고 사진이나 사진이 보이는 원문 화면을 녹화하지 않고, 권리 확인된 대체 이미지 또는 메타데이터 전용 화면을 사용합니다. 사진 파일명에도 사람 이름, 전화번호, 위치 같은 개인정보를 넣지 않습니다.
- 첫 검색과 문의 도우미를 한 번 예열합니다. 결과 중 **최신 상태 확인이 성공하고 실제 공고 링크가 열리는 후보**를 시연 후보로 미리 확인하되, 촬영 중 반환되는 순위나 문구를 임의로 바꾸지 않습니다.
- 브라우저 확대율과 창 크기를 고정하고 알림, 북마크바, 운영체제 계정명, 터미널의 환경변수와 개발자 도구는 화면에서 제외합니다.
- 아래 보조 화면을 미리 준비합니다: `docs/evaluation/retrieval_eval.appearance_v1.md`, `docs/evaluation/safety_contract.appearance_v1.md`, 저장소의 README·테스트 명령 화면. 수치를 다시 계산하지 못한 캡처에는 반드시 평가 기준일을 함께 표시합니다.

## 화면에 표시할 지표

주 화면에는 아래 값만 한 슬라이드에 표시합니다. 제목은 **“최종 frozen one-shot·24개 의미보존 문장·공고 사실 기반 silver qrels (2026-07-26)”**로 두어 사람 평가나 운영 성과로 오해하지 않게 합니다.

- Precision@5 **76.67%**, nDCG@5 **79.15%**, Hit@5 **100.00%**
- 상위 10개 inactive exposure: **0.00%**
- 의미보존 문장 중 실버 지표 하락: **8/24**
- 외형 중심 비추론 안전 계약: **4/4 PASS**

작은 각주에는 “시스템을 보지 않은 별도 작성자가 동결한 동일 저장소 범위 one-shot. 공고의 색상·체중·연령·지역·상태로 만든 silver qrels이며 사람 외형 판단·입양 적합성·사용자 만족도를 측정하지 않음”이라고 표시합니다. `structured_oracle`이나 보강 후 개발 회귀 수치는 대표 성능으로 쓰지 않습니다.

개발용 12질의의 P@5 **85.00%**는 단계별 ablation을 설명할 때만 보조 수치로 사용합니다. 같은 공고의 두 번째 사진 평가는 본편의 헤드라인으로 사용하지 않습니다. 질문이 나오면 **최초 120건 중 평가 가능 29건**, 평가 가능 질의 기준 Hit@5 **96.55%**, 전체 표본 기준 end-to-end Hit@5 **23.33%**, 감사 상태 `partial`을 항상 함께 말합니다. 실제 사람 대상 공식 포털 비교는 완료된 결과가 없으므로 수치나 개선 주장에 포함하지 않습니다.

## 개인정보·API 키·저작권 안전장치

- 서비스 API 키는 화면, 자막, URL, 터미널, 개발자 도구, 영상 설명란에 노출하지 않습니다. 데모는 `x-api-key` 헤더를 사용하고, 브라우저에서는 현재 탭의 `sessionStorage`에만 둡니다. 쿼리 문자열 키는 사용하지 않습니다.
- 업로드 사진은 검색 요청 처리 후 애플리케이션 데이터나 공고에 보관하지 않습니다. 단, multipart 처리 중 프레임워크·운영체제 임시 파일 spooling이 생길 수 있으므로 “완전한 메모리 전용”이라고 말하지 않습니다.
- 문의 준비에는 합성된 생활 프로필만 사용합니다. 이름, 개인 전화번호, 상세 주소, 이메일 주소를 입력하지 않으며 실제 메일 앱과 개인 계정 화면도 열지 않습니다.
- 공고의 보호소 연락처는 서버 스냅샷 또는 최신 공공 API에서 상태와 연락처가 신뢰된 경우에만 연결합니다. 최신 조회 실패 시 저장 연락처를 제공하더라도 `status_verified=false`, `connectable=false`로 표시하며 최신 확인 성공처럼 말하지 않습니다. 자동 전화·자동 이메일·자동 입양 신청은 하지 않습니다.
- 시연 사진과 화면에 재배포되는 공고 사진은 별도 이용 조건을 확인합니다. 확인이 끝나지 않았다면 해당 사진을 영상 파일에 삽입하지 말고, 권리 확인된 대체 이미지나 사진이 없는 메타데이터 화면을 사용합니다.
- 화면 녹화본을 배포하기 전에 프레임 단위로 API 키, 로컬 경로의 사용자명, 알림, 개인 계정, 클립보드 팝업, 불필요한 위치정보가 없는지 최종 검수합니다.
