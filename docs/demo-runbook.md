# 멍탐정 3분 데모 런북

이 문서는 공모전 심사에서 멍탐정의 핵심 가치와 안전 경계를 3분 안에 보여주기 위한 실행 순서입니다. 데모의 목표는 “AI가 입양 결정을 한다”가 아니라 “마음에 드는 외형의 실제 공고를 빨리 좁히고, 확인이 필요한 생활·성격 질문까지 준비한다”를 증명하는 것입니다.

## 데모 전 점검

```bash
conda activate dog-rag
python scripts/check_contest_readiness.py --metas data/dog_metas.json --index data/dog_faiss.index --max-age-days 7 --strict
uvicorn app.main:app --host 127.0.0.1 --port 8000
```

첫 명령이 freshness 오류로 실패하면 시연하지 말고 공공 API 스냅샷과 인덱스를 먼저 갱신합니다. `--reference-date`를 생략하면 실행 당일을 기준으로 검사하므로 오래된 스냅샷을 통과시키지 않습니다.

1. 새 터미널에서 `curl -H "x-api-key: change-me" http://127.0.0.1:8000/health`가 정상인지 확인합니다. 별도 키를 설정했다면 `change-me`를 그 값으로 바꿉니다.
2. `http://127.0.0.1:8000/demo`를 열고 API 키를 입력합니다.
3. 텍스트 검색 1회, 참고사진 검색 1회, 문의 도우미 1회를 미리 실행합니다.
4. 공공 API가 느릴 때도 검색은 고정 active-only 스냅샷으로 동작합니다. 문의 최신 상태 조회가 실패하면 실제 공고 링크를 열어 확인하는 동선을 사용합니다.

## 3분 시연 순서

### 0:00–0:25 — 문제와 한계

> “유기견 공고는 지역·품종 필터만으로는 마음에 둔 외형을 다시 찾기 어렵습니다. 반대로 사진이나 품종만 보고 성격과 입양 적합성을 추측하면 위험합니다. 멍탐정은 이 둘을 분리했습니다.”

화면 상단의 외형 중심 검색 설명과 “입양 적합성을 확정하지 않는다”는 안내를 짚습니다.

### 0:25–1:15 — 외형으로 후보 찾기

1. 참고사진을 드래그앤드롭합니다. 사진이 없을 때는 `복슬복슬한 흰색 털에 귀가 접힌 강아지`를 입력합니다.
2. 크기 `소형`, 나이 `성견`, 원하는 지역을 선택합니다.
3. `차분하고 아이와 잘 지내는` 같은 생활·성격 문구를 함께 넣어도 검색 순위에서 제외된다는 안내를 보여줍니다.
4. 필요하면 한 글자 오타가 있는 외형어를 입력해 보정 내역을 보여줍니다. 부정 외형 조건은 의미를 지원한다고 가장하지 않고 제외 경고를 표시합니다.
5. 검색을 실행하고 수집 시 active로 분류된 실제 공고 카드와 원문 링크를 보여줍니다.

설명 포인트:

- 사진·자연어는 OpenAI CLIP과 FAISS, 공고 텍스트는 BM25, 확인 가능한 공고 사실은 규칙·Graph로 함께 찾습니다.
- 외형 모드의 재정렬 조건은 크기·연령·지역과 사진 품질뿐입니다.
- 업로드 사진은 검색 요청 처리 후 영구 보관하지 않습니다. multipart 처리 과정에서 프레임워크의 임시 파일 사용은 발생할 수 있습니다.

### 1:15–2:05 — 순위가 아니라 근거 보여주기

첫 결과 카드에서 검색 점수, 조건 일치, 확인 필요 항목, 실제 공고 링크를 차례로 보여줍니다.

> “최종 점수는 후보를 먼저 볼 순서일 뿐 입양 성공 확률이 아닙니다. 정보가 없으면 가감점하지 않고 unknown으로 남깁니다.”

종료·만료·상태 미상 공고는 외형 데모 결과에 포함되지 않으며, 문의 직전에는 공공 API로 현재 상태를 다시 확인한다고 설명합니다.

### 2:05–2:45 — 보호소 문의 준비

1. 결과 카드의 `보호소 문의`를 누릅니다.
2. 원하는 성격, 하루 부재 시간, 아동·다른 동물 여부가 “예측값”이 아니라 실제 관찰 여부를 묻는 질문으로 바뀌는 것을 보여줍니다.
3. `전화 문구 복사`와 `이메일·문의폼 양식 복사`를 보여줍니다. 공공 API에 이메일이 없으면 메일 작성 링크는 숨기고 복사 양식만 제공됩니다.
4. 신뢰된 활성 공고에서 확인된 연락 수단만 바로 연결하며 자동 발송이나 입양 신청은 하지 않는다고 설명합니다.

### 2:45–3:00 — 오픈소스 가치

> “가중치, 상태 판정, unknown 처리, 안전 계약과 평가 데이터를 모두 공개했습니다. 특정 유료 LLM 없이 핵심 검색과 문의 문구가 재현되고, 국가동물보호정보시스템 공고를 다시 수집해 같은 절차를 검증할 수 있습니다. 다른 기관은 제공된 JSON bridge나 provider 계약으로 같은 상태·정규화 정책에 연결할 수 있습니다.”

README의 평가 리포트·데이터 카드·모델 카드 링크를 보여주고 종료합니다.

## 심사 질문에 대한 짧은 답

| 질문 | 답변 |
| --- | --- |
| 왜 성격까지 추천하지 않나요? | 사진·품종·짧은 공고로 성격이나 아동 친화성을 신뢰성 있게 확정할 수 없기 때문입니다. 대신 실제 보호 기간의 관찰 내용을 묻도록 연결합니다. |
| 생활정보를 버린 것 아닌가요? | 버리지 않았습니다. 순위 추측에는 쓰지 않고 후보를 선택한 뒤 보호소 확인 질문을 개인화하는 데 씁니다. |
| 품종이 대부분 믹스인데 괜찮나요? | 공고상 표기라는 출처를 표시하고 혈통으로 확정하지 않습니다. 외형 자연어·이미지 검색이 품종 필터의 한계를 보완합니다. |
| 최신 공고인가요? | 최근 갱신한 365일 범위의 active-only 고정 스냅샷을 사용하고, 문의 직전에는 공공 API로 상태를 한 번 더 확인합니다. 공고는 수시로 바뀔 수 있어 원문 확인도 함께 안내합니다. |
| 정량 근거가 있나요? | 대표 근거는 최종 frozen one-shot 24개의 P@5 76.67%·nDCG@5 79.15%·Hit@5 100%이며 실버 지표 하락 8건도 함께 공개합니다. 개발용 12질의에서는 CLIP→BM25→자연어 조건→Graph ablation을 별도로 공개하고, 안전 계약도 따로 회귀평가합니다. 공식 포털 대비 후보 3건 탐색은 4인 권장 교차·블라인드 프로토콜과 도구까지만 준비됐으며 아직 사람 결과를 주장하지 않습니다. |
| 외부 API가 끊기면요? | 핵심 검색은 로컬 스냅샷·CLIP·FAISS·BM25로 동작합니다. 최신 문의 상태만 확인 불가로 표시하고 원문 링크 확인을 안내합니다. |

## 실패 시 대체 동선

- 참고사진 오류: 텍스트-only 검색으로 전환합니다.
- 최신 상태 조회 지연: 문의 창의 실제 공고 링크를 열고, 자동으로 active라고 단정하지 않는 동작을 설명합니다.
- 네트워크 단절: 로컬 검색·점수 근거·문의 문구 생성까지 시연하고 외부 공고 링크만 사후 확인합니다.
- GPU 없음: CPU에서도 실행되며 첫 모델 로딩 시간이 길 수 있으므로 시연 전에 1회 예열합니다.
