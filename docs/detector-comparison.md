# 객체 탐지기 비교 기록

멍탐정은 공고 사진 전체와 개가 검출된 crop을 함께 CLIP 인덱스에 넣습니다. 2026-07-17의 활성 공고 표본 100장을 동일한 캐시 이미지와 GPU에서 비교한 뒤, 기본 탐지기를 TorchVision Faster R-CNN MobileNetV3-FPN으로 정했습니다.

| 탐지기 | 개 검출 이미지 | 평균 추론 시간 | 가중치 크기 |
| --- | ---: | ---: | ---: |
| YOLO11n (비교 기준) | 86/100 | 18.47 ms | 5.4 MB |
| Faster R-CNN MobileNetV3-FPN | 99/100 | 28.57 ms | 74.2 MB |
| SSDLite320 MobileNetV3 | 88/100 | 39.01 ms | 13.4 MB |

YOLO11n과 Faster R-CNN의 주 검출 영역 중앙값 IoU는 0.929였습니다. 두 모델이 함께 검출한 이미지는 85장, YOLO11n만 검출한 이미지는 1장, Faster R-CNN만 검출한 이미지는 14장이었습니다. Faster R-CNN은 더 느리고 무겁지만 오프라인 인덱스 생성 단계에서 검출 누락을 줄이는 이점이 더 크다고 판단했습니다.

이 비교는 정답 bbox와 음성 표본이 없는 탐색적 양성 표본 평가입니다. 따라서 mAP, 오검출률 또는 일반적인 탐지 성능을 증명하지 않으며, 현재 공고 사진 분포에서 crop 생성 후보를 놓치는 비율을 살핀 결과로만 해석해야 합니다. 실제 교체 후 전체 1,394건에서는 사진 다운로드에 성공한 1,380건 중 1,326건에서 개 영역을 검출했습니다.

재현 시 모델 버전, 가중치, confidence threshold, 이미지 목록과 해시, 하드웨어, 워밍업 조건을 함께 고정해야 합니다. 사전학습 가중치와 COCO 데이터의 조건은 `THIRD_PARTY_NOTICES.md`를 확인하세요.
