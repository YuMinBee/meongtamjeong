# 공고 사진·파생 벡터 이용범위 확인 문안

이 문안은 법률 자문이 아니라, 출품 전에 제공기관의 확인 응답을 받아 보관하기 위한 질문 초안입니다. 비밀 API 키, 원본 `.env`, 개인 연락처 목록 또는 사진 묶음을 첨부하지 않습니다.

## 문의 경로

- [국가동물보호정보시스템 구조동물 조회 서비스 상세 페이지](https://www.data.go.kr/data/15098931/openapi.do)의 `데이터 개선요청·오류신고 및 문의`
- 공공데이터포털 개방문의: 상세 페이지에 표시된 공식 연락처 이용
- 대회 라이선스 검토가 필요하면 [오픈소스 개발자대회 공식 문의처](https://www.oss.kr/pages/2) 또는 오픈소스 포털 라이선스 문의 경로를 함께 이용

## 제목

국가동물보호정보시스템 구조동물 공고 사진 및 파생 임베딩의 오픈소스 출품 이용범위 문의

## 본문

안녕하세요.

공공데이터포털의 `농림축산식품부 농림축산검역본부_국가동물보호정보시스템 구조동물 조회 서비스`를 활용해, 사용자가 이미지와 자연어로 구조동물 공고를 탐색하는 비영리 학생 오픈소스 프로젝트 `멍탐정`을 개발하고 있습니다.

공식 상세 페이지에는 해당 API의 이용허락범위가 `제한 없음`으로 표시되어 있습니다. 출품 소스와 데이터 고지를 정확히 구성하기 위해 아래 범위를 확인 부탁드립니다.

1. API 응답의 공고 텍스트·메타데이터를 출처와 제공기관을 표시한 JSON 검색 스냅샷으로 공개 저장소에 포함할 수 있는지
2. API 응답에 포함된 사진 URL에서 내려받은 공고 사진 일부를 검색 입력 예시로 crop하여, 공고번호·제공기관·원본 URL·변환 방식과 함께 공개 저장소에 포함할 수 있는지
3. 위 공고 사진과 crop을 OpenAI CLIP으로 변환한 512차원 임베딩 벡터를 FAISS 검색 인덱스로 공개 배포할 수 있는지
4. 허용되는 경우 필요한 출처표시 문구, 상업적 이용·변형 제한, 삭제 요청 절차 또는 별도 유의사항이 있는지
5. 사진별 제3자 권리가 포함돼 일부 범위가 허용되지 않는 경우, 허용되는 범위와 제외해야 할 산출물을 구분해 주실 수 있는지

프로젝트 소스코드는 Apache-2.0이지만 공고 데이터·사진·파생 벡터에는 이 코드 라이선스를 적용하지 않고, 제공기관이 안내한 별도 조건과 출처를 명시할 예정입니다. 입양 적합성이나 성격을 사진으로 판정하지 않으며, 공고 탐색과 실제 공고 링크 연결에만 사용합니다.

확인 가능한 공식 답변이나 적용 약관의 링크를 회신해 주시면 출품 라이선스 문서와 데이터 카드에 반영하겠습니다.

감사합니다.

## 응답을 받은 뒤 기록할 항목

- 문의·회신 날짜와 담당 기관(개인 담당자 이름은 공개 문서에서 제외)
- 답변 원문을 보관한 비공개 위치
- 허용 범위: 메타데이터 / 원문 사진 / crop / 사진 파생 벡터
- 요구 출처표시와 이용 제한
- 저장소에서 유지하거나 제외한 파일과 적용 commit

회신이 모호하면 허용으로 확대 해석하지 않습니다. 출품 시점까지 확인되지 않은 사진·crop과 사진 파생 벡터는 공개 릴리스에서 제외하고, 공식 API를 이용한 로컬 재생성 절차만 제공합니다.
